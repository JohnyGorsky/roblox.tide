## Requirements / goal

Deep-research pass producing THE list: everything that has to be built, from a crate to the Expedition Ship, grouped into work packages that can be tackled one at a time. Requested explicitly - the user needs to see the whole scope and how it divides before choosing what to start. Structure: docs/build/README.md explaining how the manifest differs from docs/systems (intent), docs/features (units of work) and docs/content (fiction catalogs), plus twelve group files ordered so each can be judged as soon as it lands. Every item carries what it is, whether a graybox is acceptable for it, and where it comes from (meshy/studio/code/store/sound). Item counts are honest planning numbers so a group can be sized before starting. Specifically requested detail: how many boat parts, and a worked example of a small island covering what is on it, which enemies, which enemy groups and which weapons. Each group file also ends with a suggested job split and the open design questions that block it.
