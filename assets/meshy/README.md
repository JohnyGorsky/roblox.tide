# Meshy Workflow

For each generated object, create a small Markdown record under the relevant category.

Suggested categories:
- `boats/`
- `boat-modules/`
- `enemies/`
- `weapons/`
- `props/`
- `buildings/`

Each record should contain:
- asset ID
- status
- Meshy prompt
- palette
- reference images used
- scale notes
- moving/separate parts
- Roblox target path
- collision notes
- animation requirements
- verification notes
