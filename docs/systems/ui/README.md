# UI System

See `../../game/gui.md` for visual direction.

## Rules

1. Keep normal HUD minimal.
2. Boat state should be visible on boat instruments where practical.
3. Never hide critical state only in tiny physical text; provide accessible overlays.
4. Radar is a station/system, not a permanent minimap.
5. Context prompts disappear when not relevant.
6. Emergency UI may temporarily become louder.
7. Mobile and gamepad interaction must be designed from the start.

## Main surfaces

- normal HUD
- interaction prompt
- quick boat status
- radar screen
- map/chart
- inventory
- storage
- upgrade station
- death/end-of-expedition summary
- lobby/loadout
