# Enemy System

## Principle

Enemies should create different crew problems.

Enemy categories:

- wildlife
- pirates/humans
- drowned/supernatural humanoids
- sea monsters
- system attackers
- bosses
- environmental threats

## Threat behaviors

Possible enemy goals:

- attack player
- damage hull
- create leaks
- stop propeller
- board the boat
- steal cargo/fuel
- disable radar/generator
- mislead navigation
- slow the boat so the storm catches up
- force the crew away from a POI

## Escalation

Start believable:
- sharks
- storms
- pirates

Then progressively introduce:
- impossible signals
- ghost ships
- drowned crew
- giant creatures
- supernatural ocean phenomena

Do not reveal every supernatural threat in the first minutes.
