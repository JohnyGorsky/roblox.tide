# Radar System

## Role

Radar is a signature progression/navigation mechanic.

It should tell the crew enough to make choices without becoming a full-information minimap.

## Upgrade idea

### Mk1
- nearby generic contacts
- basic range

### Mk2
- larger range
- classify basic POI categories

### Mk3
- identify islands/wrecks/fuel/storm/hostile vessels

### Mk4
- rare signals
- moving threats
- approximate loot quality / more precise classification

### Experimental
- biological/supernatural classification
- anomaly detection

## Example contact progression

```text
Mk1 → UNKNOWN
Mk2 → POSSIBLE VESSEL
Mk3 → BIOLOGICAL CONTACT
Mk4 → LEVIATHAN — DO NOT APPROACH
```

## Power

Radar consumes generator power.

Power competition is intentional:
- radar
- pumps
- lights
- advanced weapons

## Anti-pattern

Do not replace radar gameplay with a permanent minimap showing every POI and enemy.
