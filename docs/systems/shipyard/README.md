# Shipyard / Permanent Fleet Progression

## Principle

Permanent vessel progression is primarily **parts/component based**.

The player should think:

> I need 7 more Radar Parts and one Military Radar Core.

not only:

> I need 1,350 more coins.

## Common part categories

Keep the list understandable:

- Hull Parts
- Engine Parts
- Electronic Parts
- Weapon Parts

Potential generic side currency:
- Salvage

Salvage may support minor costs, cosmetics, crew hiring or conversion, but should not replace the main parts system.

## Rare components

Examples:
- Military Radar Core
- Heavy Diesel Block
- Twin Engine Assembly
- Marine Gearbox
- Reinforced Hull Plans
- Experimental Generator
- Cutter Blueprint
- Navigation Array

## Upgrade example

```text
Engine Mk1 → Mk2

Engine Parts         12 / 20
Mechanical/Electronic requirement as designed
Rare component        0 / 1
```

## Vessel construction projects

Example:

```text
PATROL BOAT

Hull Parts            48 / 60
Engine Parts          30 / 30
Electronic Parts      18 / 25
Weapon Parts           4 / 4

Patrol Boat Blueprint ✓
Marine Gearbox        ✓
Navigation Unit       ✗
```

When complete, the vessel becomes an owned starting option.

## Source targeting

Parts should come from thematically appropriate content.

### Engine Parts
- tanker
- engine room
- cargo wreck
- repair station

### Electronics
- radar tower
- research station
- military wreck
- radio installation

### Hull Parts
- shipwreck
- dockyard
- cargo vessel
- pirate base

### Weapon Parts
- pirates
- military island
- gunboat
- boss

This connects persistent progression to radar/navigation decisions.

## Duplicate handling

Extra common parts can:
- roll into the next upgrade tier
- convert to Salvage at controlled rates

Duplicate rare components can:
- dismantle into advanced generic materials
- contribute to alternate projects

Avoid dead rewards.
