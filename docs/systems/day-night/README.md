# Day / Night System

## Core rule

**Day = explore, loot, prepare.  
Night = survive, defend, move.**

## Day

- better visibility
- calmer average sea
- easier island scouting
- normal radar behavior
- more human/wildlife threats
- main upgrade/loot period

## Dusk

Must be a recognizable warning phase:
- warmer/darker sky
- wind increases
- birds disappear
- lamps become important
- strange radar contacts may begin
- optional "sunset in 60 seconds" warning

## Night

- lower visibility
- stronger dependence on radar/lights
- more supernatural threats
- higher chance of rough water
- power allocation becomes important
- some POIs become more dangerous or transform
- some rare POIs/events only exist at night

## Dawn

Should feel rewarding:
- supernatural enemies retreat
- visibility returns
- music/ambience relaxes
- crew assesses boat damage and resources

## Special nights

Examples:
- Dead Calm
- Heavy Fog
- Pirate Hunt
- Red Storm
- Ghost Signal
- Severe Storm
- Boss night
