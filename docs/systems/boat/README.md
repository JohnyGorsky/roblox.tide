# Starter Boat Baseline

## Role

The starter boat is the first `Vessel` implementation and the crew's initial mobile base.

The architecture must remain compatible with later larger vessels.

## Starting vessel

A battered small motor launch / ex-military utility boat, not a tiny raft.

Starting systems:

- basic hull
- one weak engine
- small fuel tank
- helm/steering
- compass
- one storage crate
- repair kit/work point
- weak deck lamp
- emergency flare
- little or no advanced radar depending on permanent progression
- minimal weapon capacity

## Major systems

- hull
- engine
- fuel
- generator/electrical
- radar
- lights
- storage/work areas
- weapon hardpoints
- repair/leaks

## Design rule

Vessel upgrades should be visually obvious. A late-run vessel should look dramatically different from its starting configuration.

## Damage model

Potential failures:

- hull breach
- leak/flooding
- engine damage
- generator damage
- radar damage
- fuel leak
- gun jam/damage
- light failure

Damage should create player/NPC tasks, not only subtract HP.
