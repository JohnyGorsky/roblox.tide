# Combat System

## Design goal

Weapons should solve different problems rather than form a simple damage ladder.

## Roles

- shotgun → boarding/close range
- rifle → distance/islands
- MG → swarms/boats
- harpoon → large creatures + utility
- depth charge → underwater threat
- flare → light/signaling/creature interaction
- searchlight → visibility/repel selected threats
- explosive → armor/groups

## Resource pressure

Ammo should matter, especially early.

The game should not become an unlimited-ammo shooter.

## Boat combat

Mounted weapons use explicit hardpoints and should create crew roles.

## Enemy/system interaction

Combat may target:
- enemy HP
- boarding ropes
- tentacles
- engines
- pirate boat components
- weak points
- creature behavior states
