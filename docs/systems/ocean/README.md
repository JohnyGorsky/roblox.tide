# Ocean / World System

## Goal

Create the feeling of a huge ocean while keeping the physical Roblox world manageable.

## Core concept

Use a reusable physical ocean window plus logical sea progression.

- player starts near the southern side
- progress is broadly northward
- storm advances from behind
- left/right edges wrap
- forward progression changes logical sea stage
- POIs are selected from curated libraries

## Sea stages

Initial direction:

1. Tropical Shallows
2. Broken Islands
3. Storm Sea
4. Military/Wreck Graveyard
5. Deep Ocean
6. Cursed Waters
7. The Abyss

Exact naming and count are tunable.

## Navigation

Players should not rely on a permanent minimap.

Signals include:
- radar
- compass
- visible lighthouse beams
- smoke
- flares
- birds
- storm clouds
- radio signals
- nautical chart
