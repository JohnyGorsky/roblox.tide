# Progression

## Three layers

### 1. Expedition progression — shared for the current run

The active vessel gains temporary run upgrades:

- radar levels
- hull reinforcement
- engine upgrades
- generator upgrades
- weapons
- storage
- lights
- pumps
- utility systems

These belong to the expedition, not to the captain personally.

Most reset when the run ends.

### 2. Permanent fleet progression — individual account

Each participating player receives their own permanent progression from the expedition.

The main progression currency is **parts/components**, not one universal token.

Common examples:
- Hull Parts
- Engine Parts
- Electronic Parts
- Weapon Parts

Rare examples:
- Military Radar Core
- Twin Engine Assembly
- Heavy Generator
- Marine Gearbox
- Reinforced Hull Plans
- Cutter Blueprint

Players use them in the Shipyard to:
- improve starting vessel systems
- unlock better starting configurations
- construct new vessel classes
- unlock deeper expedition departure points

### 3. Personal identity/mastery

Persistent:
- Captain mastery
- Engineer mastery
- Navigator mastery
- Gunner mastery
- Scavenger mastery
- Medic mastery
- discoveries/codex
- cosmetics
- owned NPC crew
- fleet collection

## Shared multiplayer rewards

Important expedition discoveries and major component drops should normally credit every eligible participating player individually.

Do not make one rare blueprint randomly belong to only one of six cooperative players unless explicitly designed as a separate optional mechanic.

## Starting-vessel progression

Permanent upgrades should improve the starting point but not remove the in-run progression.

Example:

```text
Permanent Radar cap:
Start with Mk2

During run:
Mk2 → Mk3 → Mk4 → Experimental
```

## Larger vessel unlocks

Long-term progression can build:

```text
Old Launch
→ Reinforced Launch
→ Patrol Boat
→ Trawler / Research Vessel
→ Cutter
→ Expedition Ship
```

Each vessel should preserve tradeoffs rather than forming a simple worst→best ladder.

## Deeper starts

Veteran players may unlock deeper departure points so they can skip very early content.

Tradeoff:
- harder enemies immediately
- harsher storm
- less easy loot
- higher rewards

## Failure still progresses the account

End-of-run summary can include:
- expedition XP
- role mastery
- permanent parts/components found
- discoveries/codex entries
- recovered blueprints
- cosmetics/achievement progress
- highest sea stage reached
