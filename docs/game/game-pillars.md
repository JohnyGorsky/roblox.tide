# Game Pillars

1. **The vessel is the mobile base.**
   It is not only transportation. It contains navigation, storage, power, repair, weapons, lighting and progression.

2. **The storm forces movement.**
   Players can detour, but cannot comfortably remain behind forever.

3. **Radar creates decisions.**
   It should reveal possibilities, not simply show a full minimap.

4. **Day and night play differently.**
   Day favors exploration. Night favors survival, defense and movement.

5. **The ocean feels huge without requiring a gigantic permanent map.**
   Use logical progression, wrapping and curated content windows.

6. **Enemies attack systems and plans, not only HP.**
   Some enemies stop engines, disable radar, create leaks, board the vessel or steal cargo.

7. **Minimal UI.**
   Shared vessel information should live on physical instruments where practical.

8. **Curated proceduralism.**
   Runtime chooses from approved content; uncontrolled runtime terrain generation is not the primary island strategy.

9. **Replayability through fleet growth, choices and discovery.**
   Different vessel classes, boat builds, routes, roles, rare POIs, event combinations and permanent unlocks.

10. **NPC crew support smaller parties.**
    They fill stations and perform real tasks, but skilled human coordination remains better.

11. **Permanent progression is tangible.**
    Players collect parts/components and construct or improve vessels instead of only increasing an abstract account level.

12. **Monetization must not destroy co-op survival tension.**
