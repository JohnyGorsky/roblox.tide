# Permanent Parts / Components

## Common progression parts

- Hull Parts
- Engine Parts
- Electronic Parts
- Weapon Parts

## Rare named components

- Military Radar Core
- Twin Engine Assembly
- Heavy Diesel Block
- Marine Gearbox
- Reinforced Hull Plans
- Experimental Generator
- Navigation Array
- Patrol Boat Blueprint
- Cutter Blueprint
- Heavy Harpoon Winch

## Reward rule

For cooperative expeditions, important permanent part/component progress should normally be credited to every eligible participant individually.
