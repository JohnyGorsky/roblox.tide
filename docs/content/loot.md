# Loot / Resource Catalog

Keep the economy understandable.

## In-run resources

- Fuel
- Scrap
- Ammo
- Food
- Medical supplies
- temporary/expedition repair materials

## Permanent progression drops

Common:
- Hull Parts
- Engine Parts
- Electronic Parts
- Weapon Parts

Rare:
- named ship components
- blueprints
- navigation/technology modules

## Potential special run resources

- Creature Samples
- Navigation Data
- Experimental Materials

## Rule

Do not create dozens of near-identical currencies/materials unless they produce meaningful decisions.

Players should clearly understand:

```text
SCRAP / FUEL / AMMO = current expedition

SHIP PARTS / RARE COMPONENTS = permanent fleet progress
```
