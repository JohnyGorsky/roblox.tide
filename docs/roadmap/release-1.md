# Release 1 Direction

Release 1 should prioritize:
- reliable 1–6 player boat
- clear day/night cycle
- chasing storm
- radar navigation
- 8–12 strong curated POIs/islands
- several encounter variants
- basic upgrade tree
- enough enemies to create different problems
- end-of-run progression
- cosmetic-ready boat architecture

Avoid release 1 scope inflation from:
- huge number of nearly identical weapons
- hundreds of procedural islands
- complex guilds
- advanced seasons
- deep monetization before retention is known
