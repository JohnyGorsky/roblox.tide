# 0012 — Parts/components are primary permanent fleet progression

Status: Accepted

## Decision

Main permanent fleet progression uses collectible ship parts and rare named components rather than a single universal token currency.

Common categories remain intentionally small:
- Hull Parts
- Engine Parts
- Electronic Parts
- Weapon Parts

Rare named components create targeted expedition goals.

## Why

Concrete parts connect permanent progression to exploration and radar decisions more strongly than abstract currency.
